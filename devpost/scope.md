# SettleK — 내 상황에 맞는 한국 정착 준비

한국에 사는 외국인이 자신의 상황을 설명하면, 공식 안내를 바탕으로 필요한 준비와 남은 일을 정리하고 이어서 관리하는 개인용 앱.

한국 거주 외국인을 위한 개인화된 준비·기록 관리가 기본 범위다. 기존 아이디어와 사용 경험을 참고하되 코드는 새로 구현한다. 세부 화면·기능 동작과 실제로 안내할 절차는 제품 설계에서 구체화한다.

## The Unique Kernel

같은 안내를 모두에게 보여주는 것이 아니라, 현재 상황·설명·이미 준비한 내용을 함께 반영해 **실제 준비 목록과 다음 행동이 달라지는 것**이 핵심이다. 이미 답한 것은 반복해서 묻지 않고, 필요한 이유와 공식 근거를 함께 보여준다.

## Who It's For

**대상은 한국에 사는 외국인이다.** 이사·취업·체류·교육·귀화 같은 생활 변화에 따라 개인에게 필요한 준비를 알고 관리하려는 사람을 위한 서비스다. 유학생도 대상에 포함되지만, 학생 여부나 특정 국적으로 제한하지 않는다.

시연에서는 한국에 사는 외국인의 다양한 생활 상황을 고려하고, 초기 버전에서 확인된 절차와 자료의 적용 범위를 명확히 보여준다.

## The Core Loop

1. 사용자가 현재 상황과 필요한 추가 설명을 입력한다.
2. 앱이 이미 알려진 정보를 반영하고, 빠지거나 충돌하는 정보만 묻는다.
3. 상황에 맞는 전체 준비 목록을 보여준다. 각 항목에서 필요한 이유, 받는 곳·준비 방법, 공식 출처, 추가 확인 여부를 볼 수 있다.
4. 사용자가 가진 서류와 준비 상태를 표시한다. 여러 항목을 동시에 준비할 수 있다.
5. 다시 열거나 상황을 바꾸면 기존 기록을 이어받아 남은 준비와 다음 행동을 확인한다.

## Inspiration & Identity

간결하고 이해하기 쉬운 개인용 안내를 지향한다. 반복 입력을 줄이고 현재 준비 상태와 다음 행동을 쉽게 찾을 수 있게 한다. 전체 준비 목록을 먼저 파악할 수 있고, 긴 설명은 필요한 항목에서 펼쳐본다. 한국어와 영어로 주요 흐름을 사용할 수 있게 한다.

기존 개인용 SettleK의 화면 구성, 색상, 메뉴와 사용 흐름을 유지하는 것을 목표로 한다. 홈·상황 입력·맞춤 질문·나의 계획·서류 준비·나의 기록·공식 자료·일정 알림·앱 설치를 각각 제공한다. 화면과 기능은 새 코드로 구현한다. 기업 HR 대시보드는 별도 프로젝트다.

## Why This Matters to the Learner

미국인 친구와 한국 생활에 관한 이야기를 나누고 주변의 많은 유학생을 보면서 아이디어가 떠올랐다. 한국에서 살기 위해 알아야 할 복잡한 비자·서류 준비를 더 쉽게 돕고 싶다는 것이 출발점이다.

## What "Working" Looks Like

한국에 사는 외국인의 가상 사례로 처음 입력부터 준비 상태 저장·다시 열기까지 작동한다. 같은 사용자가 취업 상황이나 이사 여부 등 지원되는 생활 변화의 조건을 바꾸면 준비 목록과 다음 행동이 실제로 달라지고, 이미 답한 내용과 준비 기록은 유지된다. 바뀐 항목에는 이유와 출처가 연결된다. 세부 시연 사례는 지원 자료와 함께 정하며, 특정 체류자격을 전체 대상과 동일시하지 않는다.

이것이 이번 시제품의 시연 기준이다. 성공 지표나 실제 이용자 효과는 아직 측정하지 않았으므로 주장하지 않는다. 짧은 영상에서 위 흐름을 보여주고 공개 저장소에 실행 방법을 제공한다.

## The POC Boundary

아래는 승인된 기본 범위다. 안내 자료별 지원 조건과 세부 동작은 PRD에서 구체화하고, 확인되지 않은 법적 요건은 기능 구현 사실로 취급하지 않는다.

- 대상은 한국 거주 외국인으로 유지하고, 상황 입력 → 맞춤 준비 목록 → 준비 상태 기록·이어가기라는 공통 흐름을 끝까지 연결한다.
- 첫 버전에서 정확히 지원할 세부 생활 변화와 절차는 공식 자료의 적용 범위를 확인해 명시한다. 검토한 범위를 넘는 경우 무엇을 추가로 확인해야 하는지 안내한다. 모든 비자·귀화 요건을 첫 버전에서 완결한다는 약속은 아니다.
- 최소한의 상황 입력, 추가 질문, 상황별 준비 목록, 출처·준비 방법, 보유 여부·준비 상태 기록을 포함한다.
- AI가 사용자의 설명에서 관련 사실을 정리해 개인화에 연결한다. 공식 서류·조건은 확인된 출처의 범위 안에서 다루고, 모르는 조건은 추가 확인으로 남긴다.
- 필요한 서류 전체를 한눈에 보여주고 여러 항목을 동시에 준비하게 한다.
- 준비 기록은 같은 기기에서 이어 쓰고, 로그인 후 사용자가 저장을 선택하면 계정에 저장·불러오기할 수 있다. 새 앱의 계정 저장 공간은 기존 앱과 분리한다. 서류 원본이나 여권번호 같은 식별정보는 받지 않는다.
- 사용자가 확인한 날짜로 일정을 등록하고 완료 상태를 관리하며 캘린더 파일로 내보낸다. 앱을 닫아 둔 상태의 자체 푸시·문자·이메일 발송은 포함하지 않는다.
- 휴대폰 홈 화면에 설치할 수 있는 웹 앱과 한국어·영어 화면을 제공한다.
- 서류 재사용 가능 여부와 준비 완료는 사용자가 직접 확인한다.
- AI 실제 연결·모의 작동·실패 상태를 구분한다. 서비스와 비용 제한은 기술 설계에 기록하고, 실제 연결 여부는 검증 기록과 구분해 표시한다.
- 공식 출처의 적용 범위와 확인 시점을 드러낸다. AI가 체류자격이나 법정 기한을 임의 확정하지 않는다.

## Later

- 초기 지원 범위 밖의 세부 체류자격·생활 변화·지역별 절차를 공식 자료와 함께 추가
- 앱을 닫은 상태의 푸시 알림과 추가 캘린더 서비스 연동
- 지원 언어와 공식 자료 범위 확대
- 실제 이용자 검토와 피드백을 통한 개선

## Explicitly Cut

- 증명서 발급·기관 신청 대행: 준비를 돕는 핵심 흐름을 입증하는 데 필요하지 않고 별도 기관 연계가 필요하다.
- 자동 비자 자격 확정·서류 재사용 승인: 제작자가 정한 사용자 확인 원칙을 지킨다.
- 기업 HR 화면: 이번 BuildAI의 개인용 사용 흐름에 포함하지 않는다.
- 기존 앱 코드 재사용: 이번 대회는 Skill Pack으로 시작한 새 프로젝트를 요구하므로 기존 앱의 구현을 복사하지 않는다.


## 최종 보완 — 2026-10-26

사용자 요청에 따라 직전 완성한 계획과 변경 후 서류를 추가·제외·재확인·유지로 비교한다. 비교용 프로필은 메모를 제외해 이 기기에만 보관하고 계정 불러오기·새 예시에서 초기화한다. E-7-1·E-7-4·D-10-1·F-2·F-6 공식 확인 안내를 추가하며 F-2/F-6에 일반 E 계열 고용주 서류를 일괄 적용하지 않는다. 확인한 출처는 15개이며 자료별 범위·확인일을 표시한다. 실제 외국인 사용 확인은 참여자가 없어 미실시이며 기술 검증과 구분한다.
