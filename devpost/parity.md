# SettleK — 기존 앱 기능 비교표

기존 개인용 SettleK의 화면·디자인·사용자 행동을 새 프로젝트에서 재현한다. 구현 코드는 복사하지 않는다.

| 화면·기능 | 재현할 동작 | 새 구현 | 실제 확인 |
|---|---|---|---|
| 홈 | 기존 색상·큰 제목·여정 카드·시작·예시 | 구현됨 | 자동 검사·로컬 및 배포 브라우저 확인 |
| 상황 입력 | 체류·목표·지역·생활 변화·선택 메모 | 구현됨 | 자동 검사·로컬 및 배포 브라우저 확인 |
| 맞춤 질문 | 알려진 값 재사용, 누락·충돌만 질문 | 구현됨 | 자동 검사·로컬 및 배포 브라우저 확인 |
| 실제 AI | Nebius의 NVIDIA Nemotron으로 상황 분석 | 구현됨 | 로컬 2개 사례와 실제 배포 브라우저 호출 확인 |
| 나의 계획 | 다음 행동·할 일·서류 전체·완료 되돌리기 | 구현됨 | 자동 검사·로컬 및 배포 브라우저 확인 |
| 서류 준비 | 여러 절차 목록·방법·공식 링크·요청문 | 구현됨 | 자동 검사·로컬 및 배포 브라우저 확인 |
| 보유·재사용 | 보유와 이번 신청의 재사용 확인 구분 | 구현됨 | 자동 검사·로컬 및 배포 브라우저 확인 |
| 기기 저장 | 새로고침·화면 이동·재접속 후 이어가기 | 구현됨 | 자동 검사·로컬 및 배포 브라우저 확인 |
| 계정 저장 | 로그인·저장·불러오기·사용자 접근 분리 | 구현됨 | 개발 계정 및 실제 배포 계정 저장·불러오기 확인; 사용자 접근 분리는 자동검사 |
| 기록 관리 | 완료 절차·백업·범위별 삭제 | 구현됨 | 기록·백업은 배포 확인; 삭제는 자동검사·로컬 확인, 실제 계정 삭제 미수행 |
| 공식 자료 | 검토 자료 검색·상황 대조·원문·적용 범위 | 구현됨 | 자동 검사·로컬 및 배포 브라우저 확인 |
| 일정 | 등록·수정·완료·계획 연결·캘린더 파일 | 구현됨 | 자동 검사·로컬 및 배포 브라우저 확인 |
| 설치 | 웹 앱 설정·지원 환경 설치·iPhone 안내 | 구현됨 | 설정·아이콘 확인; 실제 기기 설치는 사용자 확인 |
| 한국어·영어 | 메뉴·질문·결과·상태·저장 문구 | 구현됨 | 자동 검사·로컬 및 배포 브라우저 확인 |
| 화면 이동 | 아홉 주소·여섯 메뉴·직접 접속·뒤로 가기 | 구현됨 | 자동 검사·로컬 및 배포 브라우저 확인 |
| 휴대폰 | 세로 배치·하단 메뉴·터치 가능한 버튼 | 구현됨 | 로컬 좁은 화면 확인; 실제 iOS·Android 기기 확인은 남음 |

실제 AI, 개발용 로그인, 배포 환경의 계정 로그인을 각각 확인한다. 한 환경의 성공을 다른 환경의 성공으로 기록하지 않는다.

기관 신청 대행·자체 푸시 알림·전 비자 자격 판정·원본 서류 자동 판독은 기존 개인용 앱의 범위에 포함되지 않는다. 기업 HR 기능은 별도 프로젝트다.
