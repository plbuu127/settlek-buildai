# SettleK — 제품 설계

한국에 사는 외국인이 자신의 상황에 맞는 준비 목록을 확인하고, 이미 준비한 내용을 반영해 남은 일을 이어가는 개인용 서비스.

기준: `scope.md > Who It's For`, `The Unique Kernel`, `The Core Loop`.

## The Core Journey

1. **시작하기:** 한국어 또는 영어로 사용한다. 처음이면 내 상황을 입력하고, 저장한 준비가 있으면 이어서 확인한다.
2. **내 상황 설명하기:** 현재 체류 상황과 필요한 도움을 선택하고, 선택만으로 설명하기 어려운 내용은 글로 덧붙인다. 이사·취업·체류·교육·귀화 등 관련 주제를 함께 선택할 수 있다.
3. **필요한 내용만 확인하기:** 앱이 선택 답변과 설명에서 파악한 내용을 정리한다. 이미 알려진 정보는 재사용하고, 빠지거나 서로 맞지 않는 부분만 질문한다. 사용자는 내용을 수정할 수 있다.
4. **맞춤 준비 목록 보기:** 내 상황 요약, 지금 확인할 일, 관련 서류 전체를 한 화면에서 확인한다. 여러 항목을 동시에 준비할 수 있다.
5. **준비 방법 확인하기:** 각 항목에서 필요한 이유, 어디서 어떻게 받는지, 공식 출처와 추가 확인 사항을 펼쳐본다.
6. **준비 상태 기록하기:** 이미 가진 서류를 표시하고 준비 전·준비 중·준비 완료로 관리한다. 재사용 가능 여부는 직접 확인한다.
7. **다음 준비 이어가기:** 다시 열면 저장한 상황과 진행 상태가 나타난다. 상황을 바꾸면 관련 목록을 갱신하고, 달라진 항목과 이유를 확인한다.

정상 완료는 사용자가 자신의 상황에 맞는 준비 목록을 받고, 준비 상태를 바꾼 뒤 다시 열었을 때 남은 일을 이어갈 수 있는 상태다.

## Screens and Layout

기준: `scope.md > The Core Loop`, `Inspiration & Identity`.

기존 개인용 SettleK의 메뉴와 화면 구성을 따른다. 화면마다 하나의 목적을 두고, 주소로 바로 열거나 뒤로 가도 입력과 준비 상태를 유지한다.

| 화면·단계 | 먼저 보이는 내용 | 주요 행동 |
|---|---|---|
| **홈 `/`** | SettleK 소개, 한국 생활 여정, 시작·예시 버튼 | 상황 입력 시작, 저장한 계획 이어 보기 |
| **상황 입력 `/planner`** | 체류·목표·지역·생활 변화, 설명, 보유 기록 | 상황 수정, 분석에 사용할 내용 확인 |
| **맞춤 질문 `/questions`** | 빠지거나 충돌하는 정보와 질문 이유 | 답변·모름 표시·정정, 계획 만들기 |
| **나의 계획 `/plan`** | 내 상황, 다음 행동, 할 일, 전체 서류 요약 | 완료·되돌리기, 서류 준비로 이동, 계획 갱신 |
| **서류 준비 `/documents`** | 여러 절차의 서류 전체와 진행 상태 | 준비 방법·조건 확인, 보유·재사용 표시, 저장·인쇄 |
| **나의 기록 `/records`** | 저장 상태, 계정, 보유 서류와 완료 절차 | 계정 저장·불러오기, 백업 다운로드, 삭제 |
| **공식 자료 `/sources`** | 공식 안내 목록, 적용 범위, 확인 시점 | 검색·상황 대조, 근거와 원문 열기 |
| **일정 알림 `/reminders`** | 확인한 날짜, 예정·완료 일정 | 일정 등록·수정·완료, 캘린더 파일 다운로드 |
| **앱 설치 `/install`** | 설치 방법과 사용 범위 | 지원 기기에서 설치, iPhone 홈 화면 추가 안내 |

상황 입력 → 맞춤 질문 → 나의 계획의 세 단계를 표시한다. 주요 여섯 메뉴는 데스크톱 상단과 휴대폰 하단에서 접근한다. 긴 서류 설명과 생성 근거만 접어서 보여주고 전체 준비 목록은 숨기지 않는다.

## Look and Feel

- 읽기 쉬운 글자와 충분한 여백을 사용한다. 긴 설명보다 서류명·상태·다음 행동이 먼저 보인다.
- 전체 준비 목록은 숨기지 않는다. 상세 설명만 필요할 때 펼친다.
- 중요한 확인 상태와 저장 상태는 색상뿐 아니라 문구로 구분한다.
- 휴대폰에서도 항목 이름과 주요 버튼을 읽고 누를 수 있게 배치한다.
- 메뉴, 질문, 상태 표시, 버튼은 선택한 한국어 또는 영어로 일관되게 표시한다. 공식 원문의 언어는 따로 표시한다.
- 기존 앱의 밝은 회백색 바탕, 짙은 초록색 글자·버튼, 연두색 강조, 둥근 카드와 SettleK 로고 구성을 재현한다. 홈의 큰 제목과 여정 카드, 각 화면의 여백·정보 순서도 기준으로 삼는다.

## Features and Behavior

### 상황 입력과 수정

기준: `scope.md > The Core Loop`, `The POC Boundary`.

- 필요한 도움은 이사, 취업, 체류, 교육, 귀화 등 생활 변화로 표현한다. 학생 여부로 이용을 제한하지 않는다.
- 체류자격, 관련 날짜, 취업·거주 상황 등 안내를 구분하는 데 필요한 정보만 묻는다. 질문에는 무엇에 쓰이는지 짧게 설명한다.
- 모르는 항목은 모른다고 답할 수 있다. 추측한 값을 입력해야 다음으로 갈 수 있는 흐름을 만들지 않는다.
- 자유 설명을 사용할 수 있으며, AI에 보낼 내용을 사용자가 확인한다. 여권번호, 등록번호, 정확한 주소, 서류 원본은 받지 않는다.
- 입력한 내용은 수정 화면에 그대로 남는다. 처음부터 다시 입력하지 않는다.

완료 기준: 이미 입력한 상황을 수정할 때 기존 값이 보이고, 바꾼 부분만 반영할 수 있다.

### 상황 이해와 추가 확인

기준: `scope.md > The Unique Kernel`, `The Core Loop`.

- AI가 설명에서 파악한 사실을 선택 답변과 함께 사용한다. 선택 답변과 설명이 충돌하면 어느 내용을 적용할지 구체적으로 확인한다.
- 답변이 들어오면 반영됐다는 표시와 다음 질문을 보여준다. 질문이 끝나면 준비 목록으로 이동하는 버튼을 구분한다.
- 같은 의미의 답변을 여러 화면에서 다시 요구하지 않는다.
- 사용자가 모른다고 답한 조건은 필요한 기관 확인 사항으로 남길 수 있다. 무엇을 왜 확인해야 하는지 안내한다.
- 실제 AI가 결과 생성에 사용됐는지 확인할 수 있다. 시험용 응답이나 일시적인 연결 문제를 정상 AI 분석으로 표시하지 않는다.

완료 기준: 설명에 이미 포함된 사실은 목록에 반영되며, 서로 맞지 않는 정보가 있을 때는 해당 항목만 확인한다.

### 개인화된 전체 준비 목록

기준: `scope.md > The Unique Kernel`, `What "Working" Looks Like`.

- 사용자의 상황과 선택한 생활 변화에 해당하는 준비를 모아 보여준다. 같은 자료가 여러 준비에 쓰이면 중복 요청 대신 관련 목적을 함께 표시한다.
- 각 항목은 **구체적인 이름, 내게 필요한 이유, 준비 상태, 다음 행동**을 기본으로 보여준다.
- 공식 자료와 확인된 조건에 맞는 항목, 추가 조건 확인이 필요한 항목, 직접 요청하거나 상담할 일을 구분한다.
- 취업 상황, 거주 형태, 이미 가진 서류 같은 조건이 달라지면 목록·추가 질문·다음 행동도 달라져야 한다.
- 한 항목을 완료해야 다른 항목이 보이는 방식으로 만들지 않는다. 우선할 일은 강조하되 전체 목록은 확인할 수 있다.
- 상황을 바꾸면 추가·변경·해당 없음으로 바뀐 항목과 이유를 보여준다. 관련 없는 기록은 유지한다.
- 다른 신청이나 바뀐 상황에 이전의 완료·재사용 확인을 그대로 적용하지 않는다. 다시 확인할 항목을 명확히 표시한다.

완료 기준: 동일한 가상 사용자의 상황을 변경했을 때 실제 준비 내용이 달라지고, 관련 없는 준비 기록은 유지된다.

### 공식 출처와 준비 방법

기준: `scope.md > The Core Loop`, `The POC Boundary`.

- 서류별로 받는 기관이나 요청할 담당자, 준비를 시작하는 방법을 안내한다.
- 공식 발급·안내 페이지가 확인되면 바로 열 수 있다. 회사나 학교 등에 요청할 자료는 요청할 곳과 복사 가능한 짧은 요청문을 제공한다.
- 근거는 항목 옆에서 확인한다. 기관명, 자료 이름, 연결된 내용, 확인 시점과 적용 범위를 표시한다.
- 모든 비자와 모든 사람에게 동일하게 필요한 목록이라고 표현하지 않는다. 사용자 조건과 확인된 출처가 연결되는 범위를 명확하게 보여준다.
- 안내 근거가 부족한 조건은 필요한 확인 질문과 공식 문의 경로로 연결한다. 출처 없이 필수 서류나 법정 기한을 만들어 표시하지 않는다.
- 요청문 복사와 공식 사이트 이동이 실제 요청 전송·발급·신청을 완료한 것처럼 보이지 않게 한다.

완료 기준: 준비 항목에서 연결된 공식 출처와 준비 방법을 확인할 수 있고, 복사한 요청문을 실제로 붙여넣어 사용할 수 있다.

### 보유 기록과 준비 상태

기준: `scope.md > The Core Loop`, `The POC Boundary`.

- 서류 목록의 해당 항목에서 바로 보유 여부를 표시한다. 같은 서류를 기록하기 위해 절차와 종류를 다시 고르지 않는다.
- 보유하고 있다는 사실과 이번 준비에 재사용할 수 있다는 확인은 구분한다. 재사용은 사용자가 직접 확인해 표시한다.
- 준비 상태는 준비 전·준비 중·준비 완료로 변경하고 되돌릴 수 있다. 여러 항목을 동시에 준비 중으로 둘 수 있다.
- 사용자가 확인한 기록만 이후 준비에 반영한다. AI가 임의로 준비 완료나 재사용 가능 상태로 바꾸지 않는다.
- 저장한 내용은 같은 기기·브라우저에서 다시 확인하고, 사용자가 원하면 로그인한 계정에 저장한다. 브라우저 저장과 계정 저장 여부를 별도로 표시한다.
- 상황과 확인 답변, 목록, 준비 상태를 이어 쓴다. 자유 설명 원문의 보관 여부는 따로 확인하며, 보관하지 않아도 확인된 사실과 준비 기록은 유지한다.
- 새로 시작하거나 기록을 지울 때는 무엇이 지워지는지 보여주고 확인받는다.

완료 기준: 두 항목을 준비 중으로 표시하고 하나를 완료한 뒤 다시 열면 같은 상태로 이어진다. 완료를 되돌리면 남은 준비에도 반영된다.

### 계정 저장과 백업

- 로그인한 사용자가 저장 범위를 확인한 뒤 프로필·확인 답변·보유 및 준비 상태·일정을 계정에 저장하고 다른 브라우저에서 불러온다. 자동 덮어쓰기 대신 명시적인 저장·불러오기를 제공한다.
- 메모 원문, 신분증 번호, 서류 원본, API 키는 계정 저장 대상에서 제외한다. 저장 전에 전송 범위를 표시한다.
- 계정 데이터와 이 브라우저의 데이터를 구분해 삭제할 수 있다. 삭제 전 범위를 확인하고, 백업 파일을 내려받을 수 있다.
- 로그인하지 않은 상태에서는 같은 기기에 이어 쓰는 기능을 사용할 수 있다. 계정 저장 버튼에는 로그인 경로를 제공한다.
- 기존 앱의 기록을 새 앱으로 자동 이전하지 않는다. 계정별 데이터 접근을 검증한다.

완료 기준: 가상 사례를 계정에 저장한 뒤 다른 브라우저 세션에서 같은 상태를 불러오고, 다른 사용자에게는 보이지 않는다.

### 공식 자료 찾기와 상황 대조

- 정부·공공기관 자료를 검색하고, 현재 상황에 연결되는 안내와 조건을 확인한다.
- 확인한 자료의 발췌·요약과 적용 조건을 함께 표시한다. 자료가 검색되었다는 사실을 모든 법적 요건이 충족되었다는 뜻으로 표시하지 않는다.
- 새로운 자료를 실시간으로 수집한 결과인지, 미리 검토한 자료에서 찾은 결과인지 표시한다. 첫 구현은 검토한 자료 목록에서 검색·대조한다.

완료 기준: 이사와 취업처럼 다른 상황에서 관련 자료와 확인 사항이 달라지고 원문을 열 수 있다.

### 일정과 캘린더

- 사용자가 확인한 날짜로 제목·날짜·일정 종류·미리 표시할 시점을 등록한다. 법정 기한을 AI가 임의 계산해 확정하지 않는다.
- 계획의 할 일에서 일정을 추가하고, 날짜를 바꾸거나 완료를 되돌릴 수 있다.
- 등록한 일정을 일반 캘린더에서 읽을 수 있는 파일로 다운로드한다. 캘린더에 추가한 뒤의 알림은 사용자의 캘린더 설정에 따른다.
- 앱 목록의 일정 안내와 앱을 닫아 둔 상태의 푸시·문자 발송을 혼동하지 않게 한다.

완료 기준: 가상 일정을 등록·수정·완료한 상태가 유지되고, 다운로드한 캘린더 파일의 날짜와 제목이 일치한다.

### 앱 설치와 두 언어

- 지원하는 브라우저에서는 웹 앱 설치를 제공하고, iPhone에서는 홈 화면 추가 방법을 안내한다.
- 앱 이름·아이콘·시작 경로를 설정하고 휴대폰에서 주요 화면을 사용할 수 있게 한다.
- 메뉴·질문·안내·상태·오류·저장 문구를 한국어와 영어로 제공한다. 기타 언어 지원은 후속 범위로 남긴다.
- 네트워크 없이 실제 AI나 계정 저장이 된다고 표시하지 않는다.

완료 기준: 설치 설정이 유효하고 휴대폰 폭에서 주요 행동을 모두 누를 수 있으며, 언어 전환 뒤에도 입력과 진행 상태가 유지된다.

## States and Boundaries

| 사용 상황 | 사용자가 보는 내용과 앱의 동작 |
|---|---|
| 처음 방문 | 짧은 사용 안내와 내 상황 입력을 보여준다. 예시를 이용하면 가상 사례임을 표시한다. |
| 답변이 더 필요함 | 필요한 질문과 이유를 보여주고 기존 입력은 유지한다. |
| 상황을 정리하는 중 | 처리 중임을 표시한다. 같은 버튼을 반복해서 눌러 중복 요청이 생기지 않게 한다. |
| 준비 목록 완성 | 상황 요약, 전체 준비 목록, 우선 확인할 일, 근거와 생성 상태를 보여준다. |
| 저장한 내용이 있음 | 이어서 보기와 상황 수정으로 시작할 수 있다. |
| 조건이 바뀜 | 달라진 준비와 다시 확인할 항목을 보여주며 관련 없는 완료 기록을 유지한다. |
| 연결이 일시적으로 중단됨 | 입력과 마지막으로 저장한 목록을 유지한다. 다시 시도할 수 있으며 이전 결과는 이전 결과로 구분한다. |
| 저장할 수 없음 | 저장됐다고 표시하지 않는다. 현재 화면의 내용을 유지하고 다시 저장할 수 있게 한다. |
| 공식 정보만으로 확정하기 어려움 | 구체적인 확인 사항과 공식 문의 경로를 보여준다. 빈 목록을 모든 준비가 끝났다는 뜻으로 표시하지 않는다. |
| 모든 표시 항목을 준비함 | 해당 목록의 준비가 끝났음을 보여준다. 기관 신청·허가 완료와 구분한다. |

이 항목들은 입력과 준비 기록을 안정적으로 이어가기 위한 동작 정의다. 제출 시연은 정상적인 전체 흐름을 실제로 완수한 결과로 구성한다.

## Product Decisions

### 유지하는 제품 원칙

- 대상은 한국에 사는 외국인이다.
- 실제 준비 내용이 달라지는 개인화를 핵심으로 삼는다.
- 이미 입력한 정보와 보유·완료 기록을 연결한다.
- 전체 서류를 보고 동시에 준비할 수 있게 한다.
- 서류 재사용과 준비 완료는 사용자가 직접 확인한다.
- 주요 흐름을 한국어와 영어로 이해할 수 있게 한다.
- 제출 전에 핵심 기능의 실제 작동을 검증한다.

### 기존 앱과 동일하게 유지하는 구성

- 기존의 아홉 화면과 여섯 주요 메뉴를 유지한다.
- 같은 기기 저장에 더해 계정 저장·불러오기, 일정과 캘린더 내보내기, 웹 앱 설치를 포함한다.
- 원문 설명의 보관 여부와 확인된 사실·준비 상태의 기록을 구분한다.
- 기존의 색상·카드·제목·이동 흐름을 재현하되 구현 코드는 새로 작성한다. 공식 자료별 세부 조건은 재확인한다.

## What We're Building

개인 상황 입력·수정, 필요한 추가 확인, 실제 AI를 활용한 상황 정리, 공식 근거와 연결된 맞춤 준비 목록, 항목별 준비 방법, 보유·진행 상태 기록, 계정 저장과 백업, 공식 자료 검색·대조, 일정·캘린더, 웹 앱 설치, 한국어·영어 전환을 하나의 작동하는 흐름으로 만든다.

지원하는 공식 자료와 적용 조건은 문서와 화면에서 확인할 수 있어야 한다. 주제를 선택할 수 있다는 것과 모든 세부 법적 요건을 자동으로 확정할 수 있다는 것을 혼동시키지 않는다.

## Deferred From the POC

- 실시간 공동 편집과 자동 동기화: 계정 저장·불러오기는 사용자가 선택하는 방식으로 제공한다.
- 앱을 닫아 둔 상태의 자체 푸시·문자·이메일 발송: 기존 앱처럼 일정 목록과 캘린더 내보내기까지 제공한다.
- 서류 원본 업로드·자동 판독: 첫 버전은 설명과 보유 상태만으로 핵심 흐름을 입증한다.
- 전 체류자격·지역·예외 조건의 완전한 지원: 검증한 공식 자료의 범위부터 정확히 제공한다.

## Possible Later Enhancements

실제 사용자의 피드백을 바탕으로 안내 범위와 언어, 외부 캘린더 연동을 확대한다.

## Non-Goals

- 정부 서류를 직접 발급하거나 신청을 대신 제출하지 않는다.
- 체류·취업·귀화 허가 가능 여부를 최종 판정하지 않는다.
- 사용자 대신 서류 재사용이나 준비 완료를 확정하지 않는다.
- 기업 HR 관리 화면은 이 개인용 제품에 포함하지 않는다.

## 완료 확인 기준

기준: `scope.md > What "Working" Looks Like`.

1. 가상 외국인 사례로 상황 입력부터 준비 목록 생성까지 완료한다.
2. 실제 AI 응답이 상황 정리에 사용됐다는 근거를 확인한다.
3. 상황을 바꾸면 준비 항목이나 확인 질문이 실제로 달라진다.
4. 이미 입력한 정보와 관련 없는 준비 기록을 반복 입력하거나 잃지 않는다.
5. 전체 서류를 한눈에 확인하고 여러 항목을 동시에 준비할 수 있다.
6. 각 항목의 이유·받는 곳·준비 방법·공식 출처를 확인한다.
7. 기록 저장 후 다시 열어 준비를 이어가고 완료 표시를 되돌릴 수 있다.
8. 한국어·영어와 휴대폰 화면에서 같은 핵심 흐름을 완료한다.
9. 실제 개인 정보 없이 짧은 시연 영상을 만들 수 있다.
10. 계정 저장·불러오기와 사용자별 접근 분리가 작동한다.
11. 일정 등록·수정·완료·캘린더 다운로드가 작동한다.
12. 기존 앱의 아홉 화면을 같은 목적과 메뉴로 제공하고 설치 설정을 확인한다.

## Open Questions

- **기술 설계에서 조사할 사항:** 초기 안내 자료의 적용 대상, 출처별 최신성, 조건별 준비 항목을 정리한다. 자료를 확인하기 전에 특정 법적 요건·기한·서류를 확정해 구현하지 않는다.
- **기술 설계에서 정할 사항:** 기존과 같은 웹 배포·계정 저장·Nebius 연동을 새 프로젝트에서 구현하고 검증하는 방법을 정한다.
- **비교 기준:** 기능별 구현과 실제 확인 상태는 `parity.md`에서 관리한다. 화면만 있거나 모의 응답인 기능을 완료로 표시하지 않는다.
