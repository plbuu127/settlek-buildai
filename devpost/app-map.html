Where to change something

  • Screen wording and navigation: web/app/settlek.tsx and web/app/components/link.tsx; visual style in web/app/globals.css.
  • Which documents fit a situation: web/lib/planner.ts; official guidance and request text in web/data/catalog.ts. Verify applicability before changing a requirement.
  • Saved progress: web/app/state.tsx for the browser and web/lib/records.ts for account validation and ownership.
  • Calendar behavior: web/app/components/reminders.tsx and web/lib/calendar.ts.

A practice to reuse

Define the expected difference before testing AI. The same move with provided housing should produce different housing preparation from a move with an own-name lease. web/tests/planner.test.ts checks that rule, while docs/live-verification.json separately records actual provider responses. A mocked test and a live integration check answer different questions.

Open it again

Follow the repository README to set up the local database once. Then run cd web and npm run dev -- --port 4189 --hostname 127.0.0.1. Open the local app, or use the owner-private deployed preview.
