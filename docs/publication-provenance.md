# Publication provenance

Prepared 2026-10-27 KST for Build With AI: Basics.

This public-source package is a snapshot of the newly implemented Skill Pack project. It includes application source, assets, dependency lockfile, migrations, tests, run instructions, MIT license, and the approved scope, PRD, specification, checklist and app map. English planning counterparts are included.

The SettleK name, idea, design direction and user journey predate this build. The existing app's implementation was not copied. The Sites Vinext starter and dependencies are pre-existing foundation code; their retained notices still apply. The application implementation was written during this project using the Skill Pack. This statement does not replace the organizer's eligibility review.

The original local repository is preserved. The publication snapshot deliberately omits its Git history because the local author metadata contains a personal/machine identity. Publication was authorized by the creator on 2026-10-27 KST. A new snapshot commit uses the GitHub public handle and noreply address with its actual publication date. It must not be presented as the original sequence of development commits.

Excluded material: credentials and environment values, private learner profile, runtime databases and account data, generated build output, dependencies, local video recordings, unrelated files and private Git metadata. The published hosting template retains the required D1 binding but omits the owner's existing deployment project identifier. That identifier is a deployment destination, not a credential.

Code publication and hosted app access are separate decisions. The creator separately authorized public website access on 2026-10-27 KST, and the existing Site's access policy was changed to public. See `submission-checklist.md` for submission status and `verification.md` for the exact distinction between live inference, mock tests, creator verification and unperformed external-user testing.
